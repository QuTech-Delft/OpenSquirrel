OpenSquirrel is available through the Python Package Index ([PyPI](<https://pypi.org/project/opensquirrel/>)).

Accordingly, installation is as easy as running:

```bash
$ pip install opensquirrel
```

You can check if the package is installed properly by running a Python console and importing it:
```python
import opensquirrel
```

Head out to the [tutorial](./tutorial/index.md) to see how you can use it!
